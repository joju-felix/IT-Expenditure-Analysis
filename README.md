# IT Expenditure Analysis Dashboard

## Project Overview
This project focuses on analyzing organizational IT expenditure using **Microsoft Power BI**. The dashboard provides insights into actual, forecast and planned expenditure across different months, regions, business areas and cost elements.

## Objectives
- Compare actual expenditure with forecast and planned budgets.
- Analyze IT spending across geographical regions.
- Identify high-spending business areas.
- Understand expenditure distribution by cost elements.
- Support better budget planning and cost management.

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Actual Expenditure | 555.73M |
| Forecast Expenditure | 890.54M |
| Planned Expenditure | 900.40M |

## Dashboard Components
1. **Monthly Expenditure Analysis:** Comparison of actual, forecast and planned spending.
2. **Regional Analysis:** IT expenditure across different geographical regions.
3. **Business Area Analysis:** Spending distribution across departments.
4. **Cost Element Analysis:** Breakdown of expenditure into Labor, Depreciation & Amortization, Hardware & Software and Other costs.

## Key Findings
- Actual expenditure is significantly below planned and forecast spending.
- USA accounts for the largest share of regional expenditure.
- Infrastructure is the highest-spending business area.
- Labor accounts for approximately 52.24% of total expenditure.

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Business Intelligence

## Conclusion
The dashboard provides a consolidated view of IT expenditure and highlights important spending patterns. The insights can help management improve budget forecasting, monitor costs and make informed financial decisions.
